# infra-free

The zero-cost foundation: Supabase for Postgres, auth and storage, GitHub Pages for the static site. For small tools that do not justify an AWS account.

- Pick it when: you need `infra.db.postgres@1`, `infra.object-store@1`, `infra.static-host@1`.
- Status: `planned` — folder and contract exist, no implementation yet.
- Source: project-tracker.

See `CLAUDE.md` for the contract and `ADR.md` for decisions.
