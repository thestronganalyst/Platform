# web-shell

The React PWA frame (Vite, React 19, TypeScript, Tailwind 4, React Router, TanStack Query, Amplify Auth): layout, routing, role-aware navigation, theming, error boundary. Forked on generate because every app restyles it.

- Pick it when: you need `web.shell@1`, `web.route-registry@1`, `web.role-nav@1`, `web.theme@1`.
- Status: `planned` — folder and contract exist, no implementation yet.
- Source: AveHealth.

See `CLAUDE.md` for the contract and `ADR.md` for decisions.
