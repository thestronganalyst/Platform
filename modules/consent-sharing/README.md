# consent-sharing

Who may see what about whom. A patient decides what a provider sees; a parent decides what a coach and a league see about a kid. Every check is audited.

- Pick it when: you need `consent.grant@1`, `consent.check@1`, `consent.revoke@1`.
- Status: `planned` — folder and contract exist, no implementation yet.
- Source: AveHealth.
