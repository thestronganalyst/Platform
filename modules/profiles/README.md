# profiles

People, separate from logins. A person may have zero logins or one; a guardian owns managed profiles (kids, dependents), acts for them, and may issue them a restricted login.

- Pick it when: you need `profiles.person@1`, `profiles.guardian@1`.
- Status: `planned` — folder and contract exist, no implementation yet.
- Source: redesign for softball, back-port to AveHealth.
