# api-shell

The API process: FastAPI with SQLAlchemy and Alembic on Python 3.12, run on Lambda through Mangum. Routing, auth middleware, error envelope, health endpoint, database session.

- Pick it when: you need `api.router@1`, `api.auth-middleware@1`, `api.errors@1`.
- Status: `planned` — folder and contract exist, no implementation yet.
- Source: AveHealth.

See `CLAUDE.md` for the contract and `ADR.md` for decisions.
